# 노선 짜기 — 구글 플레이 출시 안내

## 0. 먼저 꼭 할 일: 서명 키 백업

- 릴리스용 업로드 키를 만들어 두었습니다. 아래 두 파일은 깃에 올라가지 않습니다.
  - `android/upload-keystore.jks`
  - `android/keystore.properties` (비밀번호가 들어 있음)
- **두 파일을 USB나 개인 클라우드 같은 안전한 곳에 꼭 따로 복사해 두세요.**
- 플레이 콘솔에서 "Play 앱 서명"을 쓰면 키를 잃어버려도 업로드 키 재설정을 요청할 수는 있습니다. 다만 며칠이 걸립니다.

## 1. 실제 광고 ID 넣고 다시 빌드

1. AdMob에서 앱(Android, 아직 스토어에 없음)을 만듭니다. 광고 단위를 두 개 만듭니다.
   - 보상형: 부활, 지원 다시 뽑기, 지원 하나 더에 씁니다.
   - 전면: 판 사이에 씁니다.
2. `android/admob.properties` 파일을 만들어 아래 3줄을 적습니다.
   ```
   ADMOB_APP_ID=ca-app-pub-...~...
   ADMOB_REWARDED=ca-app-pub-.../...
   ADMOB_INTERSTITIAL=ca-app-pub-.../...
   ```
3. 릴리스 번들을 빌드합니다.
   ```bash
   cd android && ./gradlew bundleRelease
   ```
   결과물은 `android/app/build/outputs/bundle/release/app-release.aab`입니다. 이 파일을 올립니다.
   - 파일이 없으면 테스트 광고 ID로 빌드됩니다. 비공개 테스트까지는 괜찮지만, 프로덕션에는 실제 ID로 올려야 합니다.
4. 다음 업데이트부터는 `android/app/build.gradle`의 `versionCode`를 1씩 올려야 업로드됩니다. 지금은 10, 버전 이름은 1.0입니다.
5. 스토어에 공개된 뒤 AdMob에서 앱을 플레이 스토어 등록 정보와 연결합니다.

### 간단한 설명 (80자 이내)
```
버스와 지하철로 자라나는 도시를 이어 주세요. 정류장이 넘치기 전에!
```

### 자세한 설명
```
작은 도시의 교통국장이 되어 버스와 지하철 노선을 그려 보세요.

정류장을 손가락으로 이어 노선을 만들면 차량이 달리기 시작하고, 시민들은 집에서 회사로, 회사에서 상가로 오갑니다. 도시는 날마다 자라고 정류장은 늘어납니다. 한 정류장이라도 사람이 넘치면 도시의 교통이 멈춥니다.

■ 이렇게 놀아요
· 정류장을 끌어 이으면 노선 완성. 구간을 끌어 정류장을 끼워 넣고, 탭해서 빼고, 첫 정류장에서도 늘릴 수 있습니다.
· 하루가 끝나면 시의회가 지원을 제안합니다. 새 노선, 차량, 환승 센터, 다리, 선로 중 무엇을 고를지가 실력입니다.
· 8일을 버티면 완주. 별을 모으면 다음 도시가 열립니다.

■ 여섯 도시, 여섯 가지 문제
강변 도시의 다리, 항구 도시의 여객선, 산악 도시의 케이블카, 축제 도시의 임시 증편, 자라는 신도시, 먼 거리의 광역 급행까지. 도시마다 풀어야 할 문제가 다릅니다.

■ 왜 막혔는지 알려 줍니다
정류장이 마비되면 어디가, 왜 막혔는지 짚어 주고 다음 판에 해 볼 방법을 알려 줍니다. 같은 지도로 다시 도전할 수도 있습니다.

■ 이런 분께 추천해요
· 짧은 시간에 머리를 쓰는 퍼즐을 좋아하는 분
· 지하철 노선도와 도시 만들기를 좋아하는 분
· 한 손으로 가볍게, 그러나 깊게 즐기고 싶은 분

인터넷 없이도 플레이할 수 있습니다(광고는 연결되어 있을 때만 나옵니다).
```

### 데이터 보안 양식
게임 자체는 아무것도 보내지 않습니다. 하지만 **AdMob SDK가 수집하는 항목**을 적어야 합니다.

- 데이터를 수집하거나 공유하나요? **예**
- 전송 중 암호화되나요? **예**
- 사용자가 삭제를 요청할 수 있나요? 개발자는 보관하는 데이터가 없습니다. "아니요"를 고르고, 광고 ID는 기기 설정에서 재설정한다고 적습니다.

| 데이터 유형 | 수집 | 공유 | 용도 |
|---|---|---|---|
| 기기 또는 기타 ID (광고 ID) | 예 | 예 | 광고 또는 마케팅 |
| 대략적인 위치 (IP 기반) | 예 | 예 | 광고 또는 마케팅 |
| 앱 활동 > 앱 상호작용 | 예 | 예 | 광고, 분석 |
| 앱 정보 및 성능 > 비정상 종료 로그, 진단 | 예 | 예 | 분석, 사기 방지 |

모든 항목은 "필수"이고, 처리 주체는 Google AdMob입니다.

## 4. 테스트와 출시 순서

개인 개발자 계정이 2023년 11월 이후에 만들어졌다면, 프로덕션 출시 전에 아래 조건을 채워야 합니다.

1. **비공개 테스트** 트랙을 만들고 AAB를 올립니다.
2. 테스터 **12명 이상**을 이메일 목록으로 넣고, 참여 링크를 보내 설치하게 합니다.
3. 12명 이상이 **14일 연속** 테스트에 참여한 상태를 유지합니다.
4. 플레이 콘솔의 "프로덕션 액세스 신청"에서 테스트 내용을 적고 신청합니다.
5. 승인되면 프로덕션 트랙에 출시합니다. 첫 심사는 보통 며칠 걸립니다.

조직 계정이거나 2023년 11월 이전에 만든 계정이면 1~3단계 없이 바로 프로덕션에 낼 수 있습니다.

## 5. 출시 전 확인한 것 (2026-11-14)

- targetSdk 36(Android 16), 버전 1.0(versionCode 10)
- 업로드 키로 서명한 AAB 빌드
- 테스트 광고(보상형·전면)가 실제 휴대폰에서 뜨고 닫히는 것
- 백그라운드 일시정지, 이어하기, 진동
- 모든 도시 열기 플래그 끔. 결제를 연결하기 전에는 프리미엄 구매 버튼이 보이지 않음
- 설정 → 개인정보처리방침 링크가 외부 브라우저로 열림
- 유럽 등에서는 광고 동의 창과 "광고 개인정보 설정" 버튼이 나옴(한국에서는 보이지 않음)
